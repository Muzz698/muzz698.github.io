02 • LLM FINE-TUNING / DISTILLATION • IN PROGRESS

Distill-SQL

Distilling text-to-SQL skill from large LLMs into a 1.5B model that runs on a laptop. Teacher models (Gemini, gpt-oss-120b, Qwen) generate SQL, which is kept only if it runs correctly on real databases. The verified data trains Qwen2.5-Coder-1.5B with LoRA SFT and DPO, then the model is quantized to 4-bit GGUF and served with FastAPI behind a small-model-first router.

63.4%base model on full Spider dev (1,034 questions)
0.36 smedian latency, local on a laptop
2.8 GBpeak memory

04 • LLM EVALUATION / COGNITIVE SCIENCE

Do Language Models Learn Like People?

LLMs act as participants in psychology experiments: a two-armed bandit and the Cognitive Reflection Test. I fitted Q-learning models to their choices and compared them with 44 human participants. qwen2.5:7b reached 0.90 accuracy on the human task design, but stuck to choices far more than people do.
